
# Student Grade Management System (OOP)

## Project Overview

This is a Java console-based Student Grade
Management System developed as part of the
Datheon Java Programming Internship.

The application helps teachers manage student
records, marks, grades, and academic reports.

## Technologies Used

- Java JDK 17
- Object-Oriented Programming
- ArrayList
- HashMap (recommended for future extension)
- IntelliJ IDEA

## Features

1. Add Student
2. Record Student Marks
3. Display All Students
4. Calculate Class Average
5. Calculate Class Median
6. Generate Student Report Card
7. Input Validation
8. Duplicate Student ID Checking

## How to Run

1. Install Java JDK 17 or above.
2. Open the project in IntelliJ IDEA.
3. Open GradeManager.java.
4. Run the main() method.
5. Follow the menu instructions.
